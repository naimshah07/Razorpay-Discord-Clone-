# Razorpay Clone

A modern **Razorpay landing page clone** built to replicate the visual design, layout, responsiveness, and user experience of the Razorpay website.

This project focuses on frontend development, responsive UI design, reusable components, and modern styling practices.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Navigate to the project

```bash
cd razorpay-clone
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```
